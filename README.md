# Different timelines, still progress

A static, eight-chapter awareness and reflection website about the quarter-life crisis. Open `index.html` in a browser, or serve this folder with any static web server. No build tools or dependencies are required. Compatible with GitHub Pages, including project subdirectories.

## Woodland theme

- Responsive journal layout, forest photography, and reading progress.
- Smooth chapter transitions with a short synthesized two-note sound after navigation. Use **Sound on/off** to toggle; no sound plays on initial load.
- Nine decorative leaves drift at the edges. **Motion on/off** pauses animations. System reduced-motion settings override animation preferences.
- Sound and motion preferences are saved on the device when browser storage is available. Check-in responses and personal steps are not stored.
- Keyboard navigation, visible focus, chapter heading focus, and accessible review tabs are preserved.

## Files

- `index.html`: original content and chapter/check-in interactions.
- `assets/woodland.css`: theme, responsive layouts, transitions, and leaves.
- `assets/experience.js`: sound, motion settings, and progress.
- `assets/forest-path.jpg` and `assets/woodland-light.jpg`: bundled photos so images do not depend on third-party requests at runtime.
